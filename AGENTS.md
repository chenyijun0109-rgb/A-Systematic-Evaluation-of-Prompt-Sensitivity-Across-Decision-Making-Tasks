# Repository Working Rules

## README Maintenance

Any change to project behaviour, methods, metrics, prompts, task parameters,
commands, dependencies, output schemas, experiment status, or analysis
workflow must update `README.md` in the same change.

`README.md` is the current-state entry point for the project. Detailed method
history belongs in `docs/research_log.md`, and future work belongs in
`docs/next_steps_plan.md`, but neither replaces the README update.
